# Reels Script Template for Hooks, Proof and Action

This **reels script template** is a message-and-scene tool. Write the visuals beside the words so the video does not become a spoken paragraph covered with unrelated B-roll.

## Quick answer

A usable **reels script template** is a set of fields that force decisions: audience tension, opening frame, proof, spoken line, claim boundary and CTA. Copy the structure, then fill it with your product truth — empty templates do not reduce revisions by themselves.

## Copyable script

```text
Audience:
Single promise:
Opening visual:
Hook:
Scene 2 — context:
Scene 3 — action or demonstration:
Scene 4 — proof or result:
Final line and CTA:
Required labels or disclosure:
Backup three-scene version:
```

## Filled example

```text
Audience: creators with many saved ideas but no shoot plan
Single promise: one decision filter can turn a note into a filmable concept
Opening visual: a notes app with many titles, then one selected card
Hook: “Your idea bank may not be the problem.”
Context: show that every saved title still needs a hook, proof and scene plan
Action: select one audience question and write three scenes
Proof: show the completed brief beside the original note
CTA: save the filter or open the full brief guide
Backup: note → three-scene card → finished frame
```

## Write for natural delivery

For **Reels Script Template for Hooks, Proof and Action**, use short thought units, contractions the speaker actually uses and space for pauses. Do not force a creator to perform several adjectives or claims in one breath. Mark exact legal wording separately from flexible delivery.

## Pair every line with a visual job

In **Who is this page for?**, the opening earns attention; context makes the problem recognisable; action shows the method; proof supports the promise; the final line gives a relevant next step. Delete lines that repeat what the viewer can already see.

## Record alternatives efficiently

In **Reels Script Template for Hooks, Proof and Action**, film two hooks and one clean ending after the main take. Do not record five unrelated concepts in the hope that editing will discover the strategy later.

## Script QA

- One audience and one promise.
- No unsupported guarantee.
- Product facts match approved sources.
- Spoken wording sounds natural aloud.
- Captions and on-screen labels are planned.
- The backup version preserves the same proof.

## How to fill the template without freezing

1. Write the viewer outcome in one sentence.  
2. List the proof you can show today (not ideal future proof).  
3. Script the opening 3 seconds as action + text, not a long monologue.  
4. Mark claim boundaries before you film.  
5. Record one backup ending (save CTA vs soft DM CTA).

## Common mistakes this template prevents

- Filming before the payoff is defined.  
- Using three hooks that all need different first frames.  
- Caption promising something the video never shows.

## Frequently asked questions

### Should the script be memorised?

Not necessarily. Many creators sound more natural using beats or prompts. Exact wording is appropriate for required facts and disclosures.

### How many hook options are enough?

Two or three genuinely different openings are useful. More options can delay selection without improving the concept.

### Can the script be reused?

Reuse the structure, not the exact language and example. Change the audience tension and evidence.

## Spoken + visual dual-column script

Every line has a visual verb. First second must interrupt; mid-video must insert proof.
