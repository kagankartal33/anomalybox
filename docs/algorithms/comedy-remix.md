# Comedy & Remix Algorithm Layer

Bu katman, `Ultimate_Comedy_Master_System_ZERO_LOSS_MERGED.md` içindeki komedi sistemlerini ViralBox için ölçülebilir viral operatörlere dönüştürür.

## Çekirdek Formül

```text
tanıdık gerçeklik
+ yanlış mantık
+ karakter/sistem baskısı
+ tekrar edilebilir pattern
+ yükseltme
+ tutarlı sürpriz
+ kısa button
+ remixlenebilir yüzey
= paylaşılabilir komedi fikri
```

## `comedy_remix_fit`

```text
comedy_remix_fit =
  0.18 × base_reality_clarity
+ 0.16 × wrong_logic_strength
+ 0.14 × pattern_repeatability
+ 0.14 × escalation_path
+ 0.12 × surprise_coherence
+ 0.10 × character_or_system_pressure
+ 0.08 × button_quality
+ 0.08 × remixability
```

## Kalite Kapısı

Her komedi fikri şu sorulardan geçer:

1. Base reality 2 saniyede anlaşılır mı?
2. Tek bir yanlış mantık var mı?
3. Pattern bir cümlede anlatılabiliyor mu?
4. En az iki beat yükseliyor mu?
5. Button açıklama istemeden çalışıyor mu?
6. İzleyici kendi versiyonunu üretebilir mi?
7. Mizah davranışa/sisteme mi yöneliyor?
8. Bağlamdan kopunca zarar riski düşük mü?

Başarısız adaylar `REFINE_GAME`, `RECOMPOSE`, `HUMAN_BEHAVIOR_REWRITE`, `RETARGET_TO_BEHAVIOR_OR_SYSTEM` veya `GENERATE_5_BUTTONS_AND_SELECT` aksiyonlarından birine gönderilir.
