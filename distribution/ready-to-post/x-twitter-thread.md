### Tweet 2:
```text
Mistake 1: The "Pleasantry Penalty"

"Hey guys, so today I wanted to share..."

Kills scroll momentum instantly. 

The viewer’s brain decides in 300ms whether to swipe. 

Cut directly to the first spoken consonant. Zero throat-clearing. Zero introductory filler.
```

---

### Tweet 3:
```text
Mistake 2: The Static Posture Delay

Sitting dead-center against a blank wall creates an immediate visual flatline.

Directing rule: Begin mid-action.

A hand moving into frame, a macro object placement, or an abrupt physical push creates an open loop before sound even registers.
```

### Tweet 4:
```text
Mistake 3: The Claim Without Artifact

Promising value without immediate tangible proof triggers skepticism.

If you claim to have built a $50k system, show the dashboard at second 0.5. 
If you’re reviewing skincare, show the physical texture swatch. 

Proof first. Explanation second.
```
